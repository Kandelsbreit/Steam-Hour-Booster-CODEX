# Agnia Steam Hours 1.1.0

Приложение для Windows 10/11 x64 на основе локальной версии 1.0.0. До трёх Steam-аккаунтов, сохранённые сессии и ротация до 32 игр одновременно. ASF, установленный Steam и Node.js для готовой сборки не нужны.

## Запуск и обновление

1. Скачай ZIP из [релизов](https://github.com/Kandelsbreit/Steam-Hour-Booster-CODEX/releases/latest).
2. Полностью закрой старую программу через «Выйти из программы» или меню трея.
3. Распакуй **весь ZIP** в постоянную папку. Запусти `AgniaSteamHours-win32-x64/AgniaSteamHours.exe`. Не запускай EXE внутри архива и не переноси его отдельно от остальных файлов.
4. Настройки и зашифрованные сессии 1.0.0 автоматически читаются из `%APPDATA%\agnia-steam-hours`. Исходная папка версии 1.0.0 не изменяется.
5. Для нового аккаунта введи **логин Steam** слева. В разделе «Буст» введи пароль и код Steam Guard, если Steam его запросит. Пароли и коды не сохраняются.
6. В разделе «Игры» выбери игры, размер партии и интервал ротации, затем нажми «Сохранить настройки».

## Что добавлено

- **Буст:** состояния всех аккаунтов, общий и отдельный запуск/остановка, текущая и следующие партии, обратный отсчёт и ручное переключение.
- **Игры:** кеш библиотеки, поиск по названию/AppID, поиск в магазине по кнопке, ручное добавление, популярный каталог, массовый выбор, первые 32 и снятие выбора. «Убрать» снимает выбор и удаляет собственную запись; владение игрой в Steam не меняется.
- **Бесплатные лицензии:** отдельный запрос для 1–32 выбранных AppID, не чаще одного раза в час. Только free-on-demand, без покупок и без автоматической активации. Выдачу определяет Steam; уже имеющиеся и некоторые старые бесплатные игры могут не появиться в ответе.
- **Пресеты:** готовые и до 100 собственных наборов на аккаунт. До 10 000 AppID в наборе; больше 32 распределяются по партиям.
- **Статистика:** история по дням, за сегодня, всего и по аккаунтам; поигровые локальные часы, время текущей сессии и суммарная текущая скорость. История сохраняется каждые 30 секунд и при штатном выходе. При аварийном выключении возможна потеря последних 30 секунд.
- **Цели:** цель в часах для AppID, отдельный источник — локальная оценка или полученные часы Steam, прогресс и уведомление о достижении. Цель сама не удаляет игру из очереди.
- **Автоматизация:** автозагрузка Windows, задержка автовхода 0–3600 секунд, ожидание сети, запуск свёрнутой, расписание по дням, ночные интервалы, перерывы и таймер остановки.
- **Telegram:** `/status`, `/report`, `/pause`, `/resume`, `/next`, `/diagnostics`, `/goals`, `/goal`; сообщения об ошибках и ежедневная сводка. Выключен до настройки.
- **Копии и диагностика:** экспорт и восстановление настроек, аккаунтов, пресетов, целей, статистики и кеша; зашифрованный перенос Steam-токенов; сохраняемый журнал, состояния подключений, контроль зависшего входа и перезапуск упавшего интерфейса.

## Чтобы маленький ПК работал сам

1. Успешно войди в каждый аккаунт и убедись, что вход сохранён.
2. В «Играх» включи **«Автовход и запуск при открытии программы»** отдельно для каждого нужного аккаунта и сохрани настройки.
3. В «Настройках» включи **«Запускать вместе с Windows»**. Укажи задержку, достаточную для запуска своего VPN (по умолчанию 60 секунд). Программа не запускает VPN и не определяет, готов ли именно VPN: проверяется доступность сети, далее соединение проверяется Steam.
4. При желании включи запуск свёрнутой, расписание и перерывы.

После переноса папки открой новый EXE один раз — запись автозагрузки обновится на новый путь. Программа не может сама исправить путь до своего первого запуска из новой папки.

При игре на другом ПК список игр бустера очищается. После закрытия игры возобновление происходит через 15 секунд. Если Steam разорвал сессию, повторный вход начинается через 2 минуты; при повторных конфликтах до успешного входа интервал увеличивается до 15 минут. Принудительный захват игровой сессии не используется. Временные сетевые ошибки имеют задержку от 30 секунд до 5 минут. После сна соединение восстанавливается с задержкой.

При отозванном токене или запросе Steam Guard нужен вход в окне программы. Ручная остановка отменяет ожидающий автозапуск и расписание для этого аккаунта до следующего запуска. При новом открытии программы снова применяются сохранённые флаги автовхода.

Расписание и ежедневная сводка используют локальное время Windows. Ночной интервал относится к дню начала. Например, понедельник 22:00–06:00 включает утро вторника. Одинаковое время означает полные сутки выбранных дней. Перерывы считаются по активному времени каждого аккаунта; таймер остановки — с запуска аккаунта, включая ожидание и паузы.

## Часы и трафик

Локальные часы — оценка времени отправленных активных партий. Час работы 32 игр даёт 32 локальных игровых часа. Паузы и сон ПК не считаются. **Это не подтверждённые часы Steam.** Серверные показатели показаны отдельно и могут обновляться с задержкой. Начисление зависит от Steam и лицензий.

Библиотека и серверные часы обновляются по умолчанию раз в 24 часа. Интервал настраивается; 0 отключает фоновые обновления. Используется локальный кеш, без картинок, полной загрузки каталога магазина и проверки новых версий приложения. Поиск в магазине и выдача лицензий выполняются по кнопке. При сбоях интервалы подключений увеличиваются. Telegram можно полностью выключить.

В диагностике измеряются только полезные байты HTTP поиска и Telegram за текущий запуск. Steam-протокол, TLS, VPN и заголовки в этот счётчик не входят. **Полный расход с настоящими Steam-сессиями не измерен.** Для замера используй учёт трафика Windows за выбранный период; никаких обещаний в МБ/сутки нет.

## Резервные копии

Файл `.agnia` содержит сжатые данные настроек и статистики. Без пароля и без галочки сессий он не содержит Steam-токены. Пароль от 8 символов шифрует весь архив: scrypt + AES-256-GCM с проверкой целостности. Для переноса сессий пароль обязателен. Это формат резервной копии приложения, открывать его следует через «Восстановить».

Для восстановления введи пароль копии (если установлен), выбери файл и подтверди замену данных. Некорректный файл или неверный пароль не заменяют текущие данные. При успешном восстановлении программа перезапускается. Копия без токенов сохраняет имеющиеся сессии только при полном совпадении ID и логина аккаунта; иначе нужен новый вход. Перенос действующего токена не гарантирует, что Steam его примет на новом ПК.

Telegram-токен в резервную копию не входит, Telegram после восстановления выключен. На этом же ПК его локальный зашифрованный токен сохраняется. Конфигурация Telegram доступна в отдельном разделе.

Данные находятся в `%APPDATA%\agnia-steam-hours`: `settings.json`, `features.json`, `sessions/*.dat`, `telegram.dat`. Сессии и токен бота защищены Electron safeStorage / Windows DPAPI. `store.js` из 1.0.0 сохранён побайтно.

## Telegram

Создай бота через @BotFather, напиши ему `/start`, введи токен и ID своего личного чата, затем включи интеграцию. Принимаются только свежие сообщения от этого же пользователя в личном чате. Группы и чужие отправители игнорируются. Не используй одного бота одновременно в нескольких экземплярах программы.

Команды `/pause`, `/resume`, `/next` допускают логин или `all`; без аргумента работают со всеми аккаунтами. `/goal логин AppID часы [local|steam]` задаёт цель. Пароли и Steam Guard через Telegram не принимаются. После изменения настроек Telegram включение применяется сразу. Длинный опрос — до 50 секунд, сетевые повторы — от 30 секунд до 15 минут.

## Проверки и исходный движок

Смотри [отчёт о проверках](docs/VALIDATION.md) и [сверку движка](docs/ENGINE_AUDIT.md). Из исходного `engine.js` изменён только обработчик `failure()` для восстановления после конфликта сессий. Дополнительные функции находятся в `features.js` и отдельных модулях. Кастомный игровой статус исключён.

Настоящий вход, выдача лицензий, начисление часов Steam, игра на другом физическом ПК и Telegram с реальным ботом требуют проверки с учётными данными пользователя; автоматические тесты их не подменяют.

## Сборка из исходников

Нужны Node.js 24 и Windows x64:

```powershell
cd source
npm ci
npm test
npm run test:ui
npm run pack:win
```

В среде, запрещающей дочерние тестовые процессы, можно выполнить `node --test --test-isolation=none test/*.test.js`.
Готовая папка появляется в `dist/AgniaSteamHours-win32-x64` в корне репозитория. `test:ui` создаёт отдельный профиль и отключает Steam. Для проверки упакованной программы установи `AGNIA_TEST_EXE` в полный путь к EXE.

Electron 44.3.0 и steam-user 5.3.0 сохранены из 1.0.0. Playwright используется только в разработке. Лицензия MIT.

Управление из Telegram

Выключен

Создай бота через @BotFather, напиши ему /start и укажи ID своего личного чата. Команды принимаются только от этого пользователя в личном чате.

Команды

/start · /helpПриветствие и справка
/status [логин|all]Состояние и часы Steam за 2 недели
/refresh [логин|all]Обновить библиотеку Steam сейчас
/pause [логин|all]Остановить до команды возобновления
/resume [логин|all]Возобновить по сохранённой сессии
/next [логин|all]Следующая партия
/goals [логин]Цели и прогресс
/goal логин AppID часы [local|steam]Добавить или заменить цель
/mute N · /unmuteТишина для уведомлений, N минут
/diagnosticsСостояние программы

Без логина команда относится ко всем аккаунтам. Часы Steam берутся из библиотеки: обновляются автоматически раз в сутки при онлайне или командой /refresh. Пароли и коды Steam Guard вводи только в программе. При сбоях Telegram интервалы повторов увеличиваются.

Автономная работа

Включи запуск с Windows и автовход в разделе «Игры» у нужных аккаунтов. Сначала сохрани сессии обычным входом.

После переноса папки открой EXE один раз — путь автозагрузки восстановится.

0 часов — обновление только кнопкой. Перед входом программа ждёт сеть и VPN; пароль первого входа не сохраняется.

Одинаковое время — полные сутки. Ночной интервал относится ко дню начала.

0 отключает перерывы или таймер остановки. Перерывы считаются по активному времени каждого аккаунта. Таймер включает паузы. Ручная остановка отменяет возобновление до следующего запуска.

Резервная копия

Настройки, аккаунты, пресеты, цели, библиотека и статистика в одном файле резервной копии.

С паролем весь архив шифруется AES-256-GCM. Токен Telegram не переносится. При восстановлении без сессий существующий вход сохраняется только для совпадающего аккаунта. Перед заменой данных программа запросит подтверждение.

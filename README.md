# Agnia Steam Hours 2.0.0

Windows-приложение для управления до тремя Steam-аккаунтами и очередями игр. Версия 2.0.0 работает на Wails v2 и Go: итоговый EXE не содержит Electron, Node.js или `steam-user` и не требует их установки.

## Что умеет

- отдельные подключения, сохранённые сессии Steam Guard и очереди для трёх аккаунтов;
- партии до 32 игр, ротация, ручное переключение и `ClearGames` при остановке;
- корректная пауза, если игра запущена на другом ПК, и автоматическое возобновление через 15 секунд после её закрытия;
- консервативные повторные подключения по refresh token: 30–300 секунд для сети, 120–900 секунд для конфликта сессии;
- библиотека, поиск AppID, популярные игры, бесплатные лицензии, пресеты, цели и локальная статистика;
- расписание, перерывы, stop timer, автозагрузка Windows, запуск свёрнутой и обработка сна;
- Telegram-команды, резервные копии `.agnia`, диагностика и журнал.

Steam transport реализован через [GoSteam](https://github.com/w849688611/GoSteam). Приложение не реализует Steam CM/protobuf самостоятельно.

## Запуск

Запусти `AgniaSteamHours.exe` из `build\bin`. На Windows 11 WebView2 обычно уже установлен. В противном случае Windows покажет штатное сообщение о его отсутствии.

Пользовательские данные находятся в `%APPDATA%\agnia-steam-hours`:

- `settings.json` и `features.json` — настройки, библиотека, статистика и пресеты;
- `secrets-v2\*.dat` — Steam и Telegram-секреты, защищённые Windows DPAPI;
- `migration-backup-*` — автоматическая копия старых Electron-данных при первом запуске новой версии.

Старые `sessions\*.dat`, `telegram.dat` и `Local State` не удаляются. Новая версия умеет прочитать их, затем сохраняет обновлённые секреты через DPAPI. Пароли Steam и коды Guard не сохраняются и не попадают в журнал, диагностику или Telegram.

## Резервные копии

Архив `.agnia` переносит настройки, аккаунты, пресеты, цели, статистику и кеш библиотеки. Включение Steam-сессий требует пароль от 8 символов; весь архив шифруется scrypt + AES-256-GCM. Telegram-токен в копию не входит. Перед восстановлением текущие изменяемые файлы сохраняются в `before-restore-*`.

## Telegram

После `/start` у бота укажи токен и ID личного чата. Поддерживаются `/status`, `/report`, `/pause`, `/resume`, `/next`, `/diagnostics`, `/goals` и `/goal`. Команды принимаются только из свежего личного сообщения владельца чата.

Статус Telegram теперь показывает безопасную конкретную причину: неверный токен, конфликт одновременного polling, webhook, rate limit или сеть. Один бот нельзя одновременно использовать в другом экземпляре приложения или с webhook.

## Разработка и сборка

Нужны Go 1.27+, Wails v2 и Windows 11 x64.

```powershell
go test ./...
go vet ./...
wails build -platform windows/amd64
```

Для ручной проверки реального протокола предусмотрен `go run ./cmd/steam-smoke`. Он запросит учётные данные интерактивно, не пишет их на диск и не печатает токены. Не запускай его без тестового Steam-аккаунта и явного намерения проверить вход, `PlayGamesConfirmed` и `ClearGames`.

## Ограничения проверки

Автоматические тесты используют fake Steam-клиенты. Они подтверждают бизнес-логику, DPAPI, старый формат сессий, архивы, Telegram-протокол, партии, паузы, Guard и reconnect. Реальный вход Steam, Steam Guard на живом аккаунте, фактическое начисление часов, переключение между физическими ПК, выдача лицензий и Telegram с настоящим ботом не запускались автоматически и требуют проверки владельцем аккаунта.

Подробности переноса — в [MIGRATION.md](docs/MIGRATION.md).

# Agnia Steam Hours 1.1.0

Расширение локальной версии 1.0.0: семь разделов интерфейса, раздельные настройки аккаунтов, управление библиотекой, пресеты и очередь, постоянная статистика, цели, расписание, перерывы, таймер остановки, Telegram, резервные копии и диагностика.

После полного разрыва Steam-сессии добавлено автоматическое восстановление по токену с задержками. Отправка игр и ротация сохранены; принудительный захват игровой сессии не используется. Исходное хранилище сессий осталось побайтно тем же.

## Установка

Скачай `AgniaSteamHours-1.1.0-Windows-x64.zip`, закрой старую программу через меню трея и распакуй **весь архив**. Запусти `AgniaSteamHours-win32-x64/AgniaSteamHours.exe`. Настройки и входы 1.0.0 читаются из прежней папки данных Windows. Node.js и ASF для готовой программы не нужны. Инструкция и исходники внутри.

Для автономной работы включи автовход у аккаунтов и запуск с Windows в настройках. Telegram выключен до настройки. Серверные данные по умолчанию обновляются раз в сутки; можно отключить фоновые обновления.

## Проверки

32 теста логики прошли. UI smoke test прошёл и в исходном Electron, и в упакованном Windows EXE: семь разделов, раздельные аккаунты/пресеты, настройки, цели, зашифрованный экспорт и минимальный размер окна. Ошибок JavaScript не обнаружено.

Реальные входы Steam, начисление часов, переключение двух физических ПК, выдача лицензий и доставка Telegram требуют проверки с учётными данными пользователя. Такие проверки не выполнялись. Полный расход трафика Steam не измерен. При отзыве токена Steam потребуется ручной вход / Steam Guard.

SHA-256 ZIP находится в `SHA256SUMS.txt`.

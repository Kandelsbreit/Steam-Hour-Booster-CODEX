# Agnia Steam Hours 2.0.0

Версия 2.0.0 переносит приложение с Electron на Wails v2 и Go. Интерфейс и пользовательские функции сохранены: аккаунты, библиотека, пресеты, очередь, статистика, цели, расписания, перерывы, Telegram, резервное копирование и диагностика.

Старый выпуск 1.1.0 на Electron остаётся доступен только как исторический тег и совместимый источник данных. Новая программа импортирует существующие `settings.json`, `features.json` и защищённые сессии без удаления исходных файлов.

## Установка

Запускай `AgniaSteamHours.exe`. Node.js, npm, Electron и ASF для готовой программы не требуются. WebView2 Runtime входит в Windows 11; для более старой системы его нужно установить один раз.

## Проверки

Автоматические Go-тесты покрывают сохранение данных, шифрование, импорт, очередь, ротацию, перерывы, цели, обработку конфликта игровой сессии, Telegram API и корректное завершение. Реальный вход в Steam, Steam Guard, выдача лицензий, внешний игровой ПК и отправка Telegram не выполнялись без учётных данных пользователя.

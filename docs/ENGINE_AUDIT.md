# Сверка с версией 1.0.0

Оригинальный архив: `SteamHours-1.0.0CODEX.zip`.

SHA-256: `FA4C8ACD083AA43E805A419F7548E1948CB05C0F6E9D798A5B3C9F5E668C1BAD`.

Оригинальный engine.js сохранён в `docs/engine-1.0.0.js`.
SHA-256: `F49D8B8025A837A89C0E0D52790F474D61AC343EB667A9CA9A3FD3FC205BB4A4`.

`source/src/store.js` идентичен 1.0.0 побайтно, SHA-256:
`4AF5A0709F8D0CEA0834F4CD86ABBB4133E78CBE52B8D5147E31735B0AC4F8A3`.

Единственное изменение внутри исходного класса Engine: ветка конфликтов Steam 6, 34, 50 в `failure()`.
Раньше она сбрасывала желаемое состояние и требовала ручного запуска. Теперь при наличии токена назначает повтор через 120 секунд с увеличением до 900 секунд; без токена требует входа.

Методы входа, Steam Guard, сохранения токена, отправки игр, ротации, остановки, расчёта времени, загрузки библиотеки и функции проверки AppID не редактировались. `gamesPlayed(batch, false)` сохранён. Все методы прототипа, кроме конструктора и `failure`, автоматически сравниваются с оригиналом в `engine-audit.test.js`; конструктор также не менялся по текстовому diff.

Дополнительный класс Features оборачивает действия исходного движка: ожидание сети, расписание и перерывы, статистика, кеш библиотеки, проверка зависшего входа. При паузе очищает список через оригинальный `clearGames`, при работе вызывает оригинальный `apply`. Поэтому поведение приложения дополнено, хотя исходные рабочие методы сохранены.

Поведение реального Steam при переключении двух физических ПК не проверено. Проверены события смоделированного клиента: blocked, освобождение сессии, разрыв, повтор по токену, отмена повторов и отсутствие принудительного захвата игр.

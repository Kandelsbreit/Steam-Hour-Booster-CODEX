# Проверка Agnia Steam Hours 1.1.0

Дата: 13 сентября 2026. Среда: Windows x64, Node.js 24.20.0, Electron 44.3.0.

## Автоматические проверки

- 32 теста Node.js прошли: исходные сценарии плюс сравнение движка, восстановление конфликтов, локальная статистика, граница суток, ночное расписание, перерывы, таймер остановки, ожидание сети, отмена автозапуска, цели, пресеты на 65 игр, кеш, лимит лицензий, контроль зависшего входа, шифрование/повреждение копий и фильтрация Telegram.
- UI smoke test прошёл в Electron с изолированным профилем: семь разделов, создание аккаунтов, раздельные пресеты, выбор игр, сохранение цели, автоматизация, настоящий экспорт зашифрованной копии через IPC, сохранение несохранённого ввода при обновлении состояния, отсутствие горизонтального переполнения на ширине 980 px.
- Ошибок JavaScript в интерфейсе во время проверки: 0.
- Скриншоты всех разделов сохранены локально в `.test-output/`; визуально проверены Буст, Игры, Настройки и Игры при минимальной ширине окна.
- Формат ответа поиска по названию проверен на официальном endpoint магазина Steam, запрос `terraria`.
- `store.js` совпадает с оригиналом по SHA-256. В `engine.js` diff затрагивает только обработку конфликтов в `failure()`.

## Упакованная Windows-сборка

- EXE из `dist/AgniaSteamHours-win32-x64` прошёл тот же UI smoke test: все проверки успешны, ошибок JavaScript нет.
- Версии файла EXE и продукта: 1.1.0; package.json внутри app.asar: 1.1.0.
- app.asar содержит runtime-зависимости без Playwright, packager и Electron как npm-зависимости; пользовательские settings.json, features.json, sessions и telegram.dat в сборку не включены.
- ZIP собирается из готовой Windows-папки, исходников без node_modules, документации и лицензии. SHA-256 поставляется отдельным файлом.

## Не проверено с реальными учётными данными

- Вход Steam и Steam Guard, начисление серверных часов и выдача лицензий.
- Игра на другом физическом ПК и восстановление после реального вытеснения Steam-сессии.
- Доставка сообщений настоящим Telegram-ботом.
- Перезагрузка Windows с автологином и конкретным VPN пользователя.
- Полный сетевой расход при активных Steam-аккаунтах.

Эти ограничения явно указаны в README и заметках релиза. Тестовый профиль программно запрещает Steam-подключения.
